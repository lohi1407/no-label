# No Label

Brand site for **No Label** — food sourced from its origins.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Configure contact

Edit `lib/site.ts` and set:

- `whatsapp` — E.164 number without `+` (for WhatsApp enquire links)
- `email` — enquire email address
- `phoneDisplay` — optional display string

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/products/a2-cow-ghee` | Pure Organic A2 Cow Ghee |
| `/products/telangana-samba-rice` | Telangana Samba Rice |
| `/enquire` | Enquire / order form |

Replace the CSS field gradients in product/hero sections with real photography in `public/` when ready.
