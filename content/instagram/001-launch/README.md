# Instagram 001 — Launch post

First public post for **No Label**.

## Assets

| File | Use |
|------|-----|
| `post.jpg` / `post.png` | Feed post (1080×1080) |
| `story.jpg` | Story / Reels cover (1080×1920) |
| `caption.txt` | Copy-paste caption |

## How to publish

1. Open Instagram → New post → upload `post.jpg`.
2. Paste `caption.txt` (trim hashtags into the first comment if you prefer a cleaner caption).
3. Optionally share `story.jpg` the same day with a “New” sticker linking to the post.
4. Bio CTA: enquire / WhatsApp (`+91 93929 39897`) or `hello@nolabel.farm`.
